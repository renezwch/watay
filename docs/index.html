01 · Verification Guarantee

How do you know the generated code actually works?

Most generators hand you untested template files and hope they compile. Watay only finishes a build after proving every generated method over real HTTP.

01

Live HTTP roundtrip before emit

During generation, Watay boots a local HTTP contract server from your OpenAPI spec and calls every generated TypeScript and Python method—testing auth headers, path parameters, and retries.

02

Shipped with runnable tests you own

Every generated SDK includes a standalone tests/ folder using built-in node:test and Python unittest. Run them yourself in 1 second without installing test frameworks.

03

Runtime payload guards in production

Static types disappear at runtime. Watay embeds schema guards directly into the client so if your backend ever drops a required field, you get a clear ValidationError($.data[0].amount).

04

100% deterministic output

No AI lottery. The same OpenAPI file always produces byte-for-byte identical code, giving you clean 5-line git diff pull requests whenever an endpoint changes.
